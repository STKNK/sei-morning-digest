本ツールは開発中です。このポリシーの公開の時点では、本ツールはまだ動作しておらず、Google のデータの取得も始めていません。以下は、動作を始めたときの取り扱いです。取り扱いを変える場合は、変更の前にこのページを更新します。

1. 対象

このポリシーは、Sei Takenaka が個人で使うツール「Sei Morning Digest」（以下「本ツール」）に適用されます。本ツールの利用者は、作成者本人だけです。

2. 取得する情報

本ツールは、本人の Google アカウントから、次の情報だけを読み取り専用で取得します。

  • Gmail：メッセージのメタデータ（差出人、宛先、件名、日時、ラベル）。メールの本文と添付ファイルは取得しません。権限の範囲：https://www.googleapis.com/auth/gmail.metadata
  • Google カレンダー：予定の時刻、タイトル、場所の有無、出欠の状態。権限の範囲：https://www.googleapis.com/auth/calendar.readonly

メールの送信、既読への変更、ラベルの変更、削除、予定の作成や変更は行いません（これらは要求する権限の範囲に含まれていません）。

3. 利用目的

取得した情報は、本人のために、その日の予定と確認が必要そうなメールの一覧を作る目的だけに使います。広告、分析、販売には使いません。Google Workspace の API から取得した情報を、汎用の（個人向けではない）AI や機械学習のモデルの開発、改善、学習に使うことはありません。

4. 保存先

  • 作成した一覧は、本人の Mac の上の、本人が管理する作業用のフォルダに保存します。このフォルダは、本人の Google ドライブに同期される場合があります。同期先は本人のアカウントだけです。
  • 同じメールを繰り返し表示しないための記録（メッセージの識別子と日付だけ）は、本人の Mac の上の、同期されないフォルダに保存します。
  • Google へのアクセスの許可の情報は、本人の Mac の Keychain に保存します。

5. 保存期間

  • 作成した一覧：本人が削除するまで保存します。
  • メッセージの識別子と日付：最長14日で削除します。
  • アクセスの許可の情報：本人がアクセスを取り消すか、本ツールの利用をやめるまで保存します。

6. 第三者への提供

取得した情報を、第三者に提供、販売、共有しません。本ツールは、取得した情報を、Google 以外の外部のサービス（AI のサービスを含む）に送信しません。この取り扱いを変える場合は、変更の前にこのポリシーを更新します。

7. Google のユーザーデータの取り扱い

Google の API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

8. アクセスの取り消し

Google アカウントの、サードパーティとの接続を管理する画面から、本ツールのアクセスをいつでも削除できます。詳しい手順は、Google のヘルプ「Manage connections between your Google Account and third-parties」をご覧ください。

9. 連絡先

本ツールについてのお問い合わせは、GitHub の Issues にお寄せください。

10. 改定

内容を変えるときは、このページを更新し、改定日を記載します。

Privacy Policy (English)

Effective date: October 22, 2026

The Tool is under development. At the time this policy is published, the Tool is not yet running and does not access any Google data. The following describes how data will be handled once it starts operating. This page will be updated before any change in how data is handled.

1. Scope

This policy applies to "Sei Morning Digest" (the "Tool"), a personal tool used by Sei Takenaka. The only user of the Tool is its owner.

2. Data accessed

The Tool reads, read-only, only the following data from the owner's Google account:

  • Gmail: message metadata (sender, recipients, subject, date, labels). Email bodies and attachments are not accessed. Scope: https://www.googleapis.com/auth/gmail.metadata
  • Google Calendar: event times, titles, whether a location is set, and attendance status. Scope: https://www.googleapis.com/auth/calendar.readonly

The Tool does not send email, mark messages as read, change labels, delete anything, or create or change events (these actions are outside the requested scopes).

3. Purpose

The data is used only to create, for the owner, a list of the day's events and of emails that may need attention. It is not used for advertising, analytics or sale. Data obtained through Google Workspace APIs is not used to develop, improve or train generalized (non-personalized) AI or machine-learning models.

4. Storage

  • Generated lists are stored in a working folder controlled by the owner on the owner's Mac. This folder may be synchronized to the owner's own Google Drive; it is synchronized only to the owner's account.
  • Records used to avoid listing the same email repeatedly (message identifiers and dates only) are stored in a non-synchronized folder on the owner's Mac.
  • Authorization credentials for Google are stored in the macOS Keychain on the owner's Mac.

5. Retention

  • Generated lists: kept until the owner deletes them.
  • Message identifiers and dates: deleted after at most 14 days.
  • Authorization credentials: kept until the owner revokes access or stops using the Tool.

6. Sharing

The data is not provided, sold or shared with third parties. The Tool does not send the data to external services other than Google, including AI services. This policy will be updated before any change to this practice.

7. Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Revoking access

In the Google Account page for third-party connections, choose "Access to your Google Account", select the Tool, then "See details", "Remove access" and "Confirm". See Google's help article "Manage connections between your Google Account and third-parties".

9. Contact

Please send questions about the Tool through GitHub Issues.

10. Changes

Any change will be published on this page with the revision date.
